# Security Policy

Form Builder is a portfolio project under active development. We take security
reports seriously and appreciate contributions that help keep the project safe.

## Supported Versions

The project has no stable releases yet. Security fixes are applied to the
default branch. A version support matrix will be published once a stable
release is made.

## Reporting a Vulnerability

Please **do not open a public issue** for security vulnerabilities.

Report vulnerabilities privately via one of the following channels:

- **GitHub Security Advisories**: use the "Report a vulnerability" button on the repository's _Security_ tab (preferred).
- **Email**: kprinny@gmail.com

Please include as much of the following as possible:

- A description of the vulnerability and its impact.
- Affected versions or the exact commit/revision.
- Steps to reproduce (a minimal example is ideal).
- Any suggested fix, if you have one.

## Response Policy

- **Acknowledgment** — within 72 hours of receiving a report.
- **Investigation** — we will investigate and provide a status update as soon as information is available.
- **Disclosure** — we prefer coordinated disclosure and would appreciate the reporter refraining from public disclosure until a fix is available (typically up to 90 days).

## What Should NOT Be Reported

The following do not belong in the private security channel — please use the
issue templates instead:

- General bugs, feature requests, or usage questions (see [SUPPORT.md](SUPPORT.md)).
- Dependency version mismatch or lint/formatting feedback.
- Information that is not related to the security of this project.
