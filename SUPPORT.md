# Support

Thanks for using Form Builder. This page explains where to get help.

## Where to Ask Questions

The primary channel for questions is **[GitHub Issues](https://github.com/reisene/formbuilder/issues)**.

If the Q&A style of GitHub Discussions becomes necessary for the project, this
section will be updated. Until then, please use Issues.

## Bug Reports

- Open an issue using the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md).
- Include steps to reproduce, expected vs. actual behavior, screenshots (if applicable), and environment details (OS, browser, Node/npm versions, package versions).

## Feature Requests

- Open an issue using the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md).
- Describe the problem you are trying to solve and the solution you would like.

## Security Issues

Do **not** report security issues in public issues. See [SECURITY.md](SECURITY.md) for the private reporting process.
